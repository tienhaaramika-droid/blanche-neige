🏁 Blanche-Neige: Gran Turismo Autostrada
The ultimate retro-'80s 944 arcade game
Welcome to Gran Turismo Autostrada, a small retro arcade game starring Blanche-Neige, my white Porsche 944 Cabriolet.

The idea is simple: take an old-school sports car, add an Italian autostrada, a neon sunset, some synths and the spirit of the great 1980s driving games.

Then make things progressively less sensible.

Drive Blanche-Neige into the sunset, avoid the traffic, survive unexpected road hazards and see how far you can get.

🎮 How to play
ENTER — Start / restart
← / → or A / D — Steer
↑ or W — Turbo
M — Radio on/off
R — Change radio track
🎵 Radio Autostrada
Three original retro-inspired tunes accompany the drive:

Sunset Run — fast, bright arcade energy
Neon Coast — a more relaxed coastal-night groove
Alpine Night — slower, darker mountain driving
Turn up the sound.

🏎️ The road gets stranger
The longer Blanche-Neige survives, the more unpredictable the Autostrada becomes.

There is traffic.

There are mountains.

There are palm trees.

There may even be camels.

And after that, no promises.

🌅 About the game
This started as a simple experiment: could I make a little 1980s-style arcade game starring my own Porsche 944?

One idea led to another.

A grey road became a neon Autostrada.
A rectangle became Blanche-Neige.
One synth loop became a radio station.
Traffic started appearing over the horizon.

And then the camels arrived.

The game runs completely in the browser using HTML, CSS, JavaScript and the Web Audio API. No installation is required.

🚘 Why Blanche-Neige?
Because every proper arcade-driving game needs a hero car.

Mine happens to be a white Porsche 944 Cabriolet called Blanche-Neige.

So buckle up.

Press Enter. Turn up the sound. Drive into the sunset.

Built for curiosity, nostalgia and absolutely no practical reason whatsoever.
